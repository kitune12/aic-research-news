モデル廃止

GitHub Copilot、一部モデルを12月14日に廃止

Claude・Gemini・Grok の複数モデルが対象、代替モデルへの切り替えを案内

GitHub は11月13日、Copilot で提供している一部の AI モデルを12月14日に廃止すると発表した。モデルを固定指定している利用者は、設定の見直しが必要になる。

発表によると、Claude Fable 5 は 5.2 に、Claude Haiku 4.5 は 5.5 に置き換わる。年額の個人プランについては継続される。Gemini 3.8 Flash は Gemini 4 Hydrogen に、Gemini 4 Argon は Gemini 4 Carbon に、Grok 4.6 は 4.7 に移る。

一方で Kimi K3 には代替モデルが示されていない。廃止の期日は12月14日だ。

AI モデルの世代交代が月単位で進むなか、特定モデルを名指しで設定に固めている場合は、期日までに見直さないと動作に影響が出るおそれがある。利用中のモデルがいつ廃止されるかを把握しておく運用が求められそうだ。

企業 AI

OpenAI と Databricks、企業データ上での利用を拡充

GPT-6 系と gpt-oss を、SQL・ノートブック・エージェントから呼び出せるようになる。Codex 向けプラグインや ChatGPT との接続も用意される。提携は2025年9月に始まった複数年契約で、提供日や数値は示されていない。

資金調達

LangChain がシリーズ C で3億ドル、評価額30億ドル

CapitalG がリードした。資金はエージェントの運用基盤 LangSmith に充てられる。エージェントを作る段階から、管理・統制する段階へ投資の対象が移りつつあるとみられる。

資金調達

Mercor が7.5億ドルを調達、評価額200億ドル

シリーズ D で、Nvidia や Salesforce などが参加した。専門人材を AI モデルの学習に配置する事業を手がける。AI の学習データを人が作る市場に、資金が集まり続けている。

開発ツール

GitHub のコードスキャン AI Scan、REST API で管理可能に

公開プレビューとして、組織やリポジトリ単位で `repository_scan` を切り替えられる。有効にしてもスキャンは自動では始まらず、実行のたびに AI クレジットを消費する。GHES は非対応。
