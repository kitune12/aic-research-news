Fireworks AI への攻撃で Notion 顧客の AI チャット記録が流出

推論基盤の外部委託先が2か月で2度目の侵害、Notion は約1%の顧客に影響

AI 推論基盤を手がける Fireworks AI がサイバー攻撃を受け、Notion AI を利用する顧客の一部のチャット記録に攻撃者がアクセスした。TechCrunch が11月12日に報じた。

報道によると、流出したのは Fireworks の課金情報と一部のデータセットだ。Notion では、「Insights」機能を使う Notion AI 顧客のチャット記録が対象になった。影響を受けたのは自社顧客の約1%という。

Notion は11月3日に Fireworks との接続を遮断し、保存していたデータも削除した。Fireworks の侵害は10月に続くもので、2か月で2度目にあたる。

AI 機能を外部の推論事業者に任せる構成は、いまや多くのサービスで一般的だ。今回の件は、そうした委託先がサプライチェーン上のリスクになりうることを示している。利用者側にも、チャット記録がどこで処理・保管されるかを確認する視点が求められそうだ。

鳥インフル

千葉県旭市で高病原性鳥インフルエンザの疑似患畜、今季国内2例目

農林水産省によると、旭市の採卵鶏農場(約4万羽)で11月13日8時に遺伝子検査で確認された。殺処分に加え、半径3km以内は移動制限、3〜10kmは搬出制限となる。全都道府県に注意喚起も出された。

半導体

AMD が Instinct MI430X を公開、HBM4 432GB を搭載

AI と HPC の両方に使う GPU で、メモリ帯域は最大23.3TB/s、FP64理論ピークは最大288TFLOPS、FP4は9.2PF。性能値は解析モデルと初期シリコンの目標に基づく予測で、実測ではないと脚注に明記されている。メモリ容量を差別化の軸に据えた。

開発ツール

Copilot アプリが GitHub Enterprise Server 対応を一般提供

従来はオプトイン方式のプレビューだった。利用にはアプリ1.2.0以降が必要で、先に GitHub.com か GHE.com でサインインする必要がある。GHES ではクラウドセッションは使えない。

開発ツール

GitHub Actions のホステッドランナー、ARM32 を12月8日までに終了

Linux と Windows の ARM32 でのジョブ実行が対象。Node 20 のサポート終了に続く措置で、Node 24 が ARM32 に対応していないことが理由とされる。該当するワークフローは移行の検討が必要になる。

資金調達

Edelbyte が7,000万ドルを調達、AI エージェント向けデータ基盤

リードは Sequoia と Quiet Capital。検索・分析・ベクトル・グラフ・地理空間のデータを1つの基盤で扱える。料金は従量課金で、計算は vCore 時間、保存は GB・月で計算し、最低利用額はない。
